    Help

    How to use

    Create a Program for your goal, add Workout Days to it, then add exercises from the library to each day. Use Log to record what you actually did — sets, reps, weight, RPE. The Dashboard, Stats and Calendar update automatically from your logged sessions.

    How backup works

    Export backup saves everything (programs, exercises, favorites, history, measurements, goals, templates, settings, achievements, notes) into one JSON file named like WorkoutPlanner_2026-07-07.json. Keep this file somewhere safe (cloud drive, email to yourself).

    How restore works

    Use Import backup and choose a previously exported JSON file. You'll be asked to confirm whether to merge with existing data or overwrite it completely before anything changes.

    Migrating to a new device or browser

    Export a backup on the old device, transfer the file (email, cloud storage, USB), then import it on the new device before you start logging new workouts there.

    FAQ

    Is my data uploaded anywhere? No. Everything stays in this browser's local storage on this device.

    Why did my data disappear? Clearing site data, private browsing, or reinstalling your browser can erase it. Always keep a backup export.

    Can I use kg and cm instead of lb and in? Yes, switch units anytime in Settings.
